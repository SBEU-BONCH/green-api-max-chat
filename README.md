# MAX Chat

Текстовый чат на React и TypeScript с отправкой и получением сообщений через GREEN-API. Интерфейс построен по образцу веб-версии MAX: список чатов слева, переписка и поле ввода справа. На узком экране список и переписка открываются отдельно.

## Запуск

Нужен Node.js 22 LTS (от 22.12) или 24 LTS.

```sh
npm ci
npm run dev
```

Приложение доступно по адресу `http://127.0.0.1:5173`. Данные инстанса вводятся в форме подключения, переменные окружения не нужны.

## Подключение к MAX

1. Создайте и авторизуйте инстанс MAX в [личном кабинете GREEN-API](https://console.green-api.com/) по [инструкции сервиса](https://green-api.com/v3/docs/before-start/).
2. В настройках инстанса включите «Получать уведомления о входящих сообщениях и файлах» (`incomingWebhook: yes`). Поле Webhook URL должно быть пустым. Дождитесь применения настроек.
3. Введите `idInstance` и `apiTokenInstance`. Если `apiUrl` в кабинете отличается от адреса по умолчанию, укажите его в разделе «Адрес API».
4. Создайте чат по номеру телефона получателя и отправьте текст. Номер вводится с кодом страны: `+7` и десять цифр или `+375` и девять цифр. Поиск номера зависит от настроек приватности получателя.
5. Ответьте из MAX на стороне получателя. Ответ появится в переписке.

Для проверки используйте отдельный аккаунт и инстанс. Привязка аккаунта даёт GREEN-API возможность работать с его сообщениями. Приложение проверяет настройки инстанса, но не меняет их. Не запускайте несколько клиентов на одной очереди уведомлений: они будут забирать события друг у друга.

## Устройство проекта

| Файл                        | Назначение                                                |
| --------------------------- | --------------------------------------------------------- |
| `src/api/greenApi.ts`       | HTTP-запросы, проверка адреса API и обработка ошибок      |
| `src/chat/model.ts`         | Типы сообщений, reducer чатов и проверка номера           |
| `src/chat/notifications.ts` | Разбор уведомлений и последовательное чтение очереди      |
| `src/chat/useChat.ts`       | Связь состояния и API с React, отмена запросов при выходе |
| `src/chat/*.tsx`            | Список чатов, переписка, создание чата и ввод сообщения   |

`CheckAccount` находит `chatId` по номеру телефона. Отправка выполняется методом `SendMessage`. Входящие события читаются через `ReceiveNotification` и подтверждаются через `DeleteNotification`. Неподдерживаемые события тоже подтверждаются, чтобы не блокировать очередь. Дубли сообщений отбрасываются по `idMessage`.

Получение восстанавливается после временных ошибок с задержкой от одной до тридцати секунд. Ошибка авторизации или настроек останавливает запросы и отображается в интерфейсе. Отправка автоматически не повторяется: при потере ответа сервера повтор мог бы создать дубль. Текст при ошибке остаётся в поле ввода.

## Проверки и сборка

```sh
npm run lint
npm run format:check
npm test
npm exec playwright -- install chromium
npm run test:e2e
```

Модульные тесты проверяют API-клиент, номера, состояние чатов и очередь уведомлений. Браузерные тесты запускаются в Chromium с обычным и мобильным размером экрана. Они используют подставной API и вымышленные данные, включая проверки ошибок, отмены запросов и хранения ключей. Эти проверки не заменяют обмен сообщениями через реальный инстанс.

```sh
npm run build
npm run preview
```

Сборка находится в `dist/` и подходит для статического хостинга. В GitHub Actions запускаются проверки и публикация на GitHub Pages.

## Данные и ограничения

Ключ и переписка хранятся только в памяти вкладки. После обновления страницы нужно подключиться заново. Приложение не использует cookies, localStorage, sessionStorage или аналитику.

Ключ передаётся непосредственно GREEN-API в URL запроса по формату их API. Разрешены только HTTPS-адреса `api.green-api.com` и его числовых кластеров. Content Security Policy дополнительно ограничивает сетевые запросы доменами API сервиса. Не публикуйте сетевые трассировки и скриншоты с ключом.

Кнопка «Выйти» прекращает запросы и очищает состояние приложения, но не отзывает доступ GREEN-API к MAX. Для отзыва завершите соответствующую сессию в разделе «Устройства» приложения MAX и смените ключ или удалите инстанс в кабинете GREEN-API.

Поддерживаются личные текстовые чаты. Загрузка старой истории, файлы, группы, звонки, статусы доставки и синхронизация исходящих сообщений из других клиентов не реализованы.

Документация: [SendMessage](https://green-api.com/v3/docs/api/sending/SendMessage/), [получение через HTTP API](https://green-api.com/v3/docs/api/receiving/technology-http-api/), [CheckAccount](https://green-api.com/v3/docs/api/service/CheckAccount/).
